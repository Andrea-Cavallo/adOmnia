# Hub game launcher and full-window play

Scope: the LET'S PLAY! launcher, full-window game presentation, and Settings description.

Direction: the requested Nothing Phone style, using the Hub's existing Doto typeface, monochrome palette and rounded controls. The game uses the active application palette.

No actionable findings in the changed interface.

- The launcher appears only when the existing opt-in setting is enabled; the default remains false (R-24, C-2).
- A native modal dialog fills the application viewport, keeps keyboard focus inside, and restores focus to the launcher when closed (R-03, R-34).
- Closing unmounts the game. Escape pauses it; Resume continues it. The game starts only after an explicit launcher click (R-19, C-2).
- The game scales its pixel rendering with available height; the previous 160/240px strip is removed (C-3).
- Verified in Chromium at 1440×900 and 600×700, including reduced-motion preferences. No page errors. Build and 43 focused tests passed.

Native Wails/WebView interaction remains a manual acceptance check.
