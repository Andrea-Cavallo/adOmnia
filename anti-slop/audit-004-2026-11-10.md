# Undead encounters, terrain and ranged sword

Direction: the supplied moonlit graveyard reference for visual treatment, and the supplied haunted forest/scythe monster reference for level and enemy variation. Additional assets were prepared using built-in imagegen and saved inside the project.

No outstanding presentation findings in this scope.

- J launches a separate sword, with direction, lifetime, cooldown and swept enemy collisions. X remains melee. The control legend distinguishes both actions.
- Zombies appear in the opening region; the enemy cast includes the blue-hooded Reaper. Each has its own animated atlas cells.
- Cemetery, forest and abbey backgrounds change with camera distance and blend before region boundaries. Region names follow the same camera coordinate.
- Terrain elevation is shared by collision detection, player movement, enemy placement and stone stair rendering. Uphill/downhill movement and resize preservation are covered by focused tests.
- The paused view keeps the knight visible even if the run was paused during an invulnerability blink.
- Chromium checks exercised J and X independently, jump, pause/resume, close/reopen and all three regional renders. Later-region screenshots use test-only starting offsets and a seeded world; production has no teleport/debug hook. No browser page errors were observed.

Native Wails acceptance remains a manual check. Browser checks do not establish native input or performance behavior.
