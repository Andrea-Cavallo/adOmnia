# Sketch Manifest

## Design Direction

Dark, technical and compact, consistent with adOmnia. Errors should explain the failure in plain language first, expose raw network details only on demand, and keep recovery actions close to the cause. Red is reserved for the state and icon; surfaces remain neutral so the error does not overwhelm the workspace.

## Reference Points

- Existing adOmnia Response panel and dark theme
- Desktop developer tools with progressive disclosure
- User-selected hybrid direction: clear summary plus expandable technical detail
