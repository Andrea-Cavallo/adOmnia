# Support

Use the right channel so reports can be handled cleanly.

## Bugs

Open a GitHub issue using the bug report template:

https://github.com/Andrea-Cavallo/adOmnia/issues/new/choose

Include:

- adOmnia version or artifact name.
- Operating system.
- Steps to reproduce.
- Expected and actual behavior.
- Logs or screenshots with secrets removed.

## Feature Requests

Open a GitHub issue using the feature request template:

https://github.com/Andrea-Cavallo/adOmnia/issues/new/choose

Good feature requests describe the workflow, not only the UI control.

## Security

Do not report vulnerabilities in public issues. Follow [.github/SECURITY.md](.github/SECURITY.md).
