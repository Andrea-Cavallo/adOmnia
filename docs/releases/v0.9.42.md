# v0.9.42 — Go Studio: Concurrency View, race comparison and an IDE-grade editor

This release closes most of the 2027 checklist's Concurrency View (§8) and
Race Detector UX (§9), and ships the editor, navigation and project work of
§2–§4.

## Concurrency View

- **Find goroutines fast.** Filter by All, Blocked or Running, or search by
  id, function or channel. Group by package and starting function, or by
  **identical stack**: 200 identical workers become one row with ×200.
- **Relations.** Each goroutine shows what it touches: channel, mutex or
  RWMutex, WaitGroup, context (waiting on `ctx.Done()`), network (I/O wait,
  net/http, gRPC, Kafka clients), database (database/sql, pgx, MySQL,
  SQLite, Mongo, Redis) and timers.
- **New diagnostics:**
  - *Channel without consumer / producer*: goroutines wait to send on a
    channel that nobody is receiving from in this snapshot, or the other
    way round.
  - *RWMutex contention*.
  - *WaitGroup never reaches zero*: goroutines wait on a WaitGroup and no
    goroutine is running to call `Done`.
  - *Excessive goroutine count*: 1000 or more at one pause.
- **Evidence badges.** OBSERVED means the diagnosis comes from the paused
  runtime snapshot. CONFIRMED means the Go runtime reported it (race
  detector).
- **Timeline.** A bar per pause, split by state, shows whether goroutines
  keep growing between pauses.
- **Copy snapshot.** Goroutines, diagnostics and races as JSON, to attach
  to an issue.

## Race detector

- **Run with Race Detector** runs the active configuration with `-race`
  (secret variables are not requested for this run), next to *Test Current
  Package with Race Detector*.
- **Compared across runs.** Each race says whether it is new in the latest
  run, recurring, or not in the latest run any more, and how many times it
  was reported.
- The two accesses are marked **EARLIER** and **LATER**.

## Editor, navigation and project

- Editor core: Sticky Scopes, Minimap, Font Ligatures, Zoom, Zen Mode,
  Preview Tab, Type Hints, save on focus change, trim trailing whitespace,
  `.editorconfig`, Replace in Files through the change preview.
- Call and Type Hierarchy, Go to Test with generation, Recent Locations,
  Last Edit Location, Next/Previous Problem, Code → Generate….
- Opt-in vulnerability diagnostics through gopls.
- Project tree decorations for Git status, problems and failed tests, and
  new icons.
- go.work management and Clone Repository.

## Verified

- Go Studio Go tests pass.
- 791 frontend tests across 175 files, TypeScript, the production build and
  the startup budget pass.
- The Concurrency View was checked against a simulated paused session; a
  real Delve session with blocked goroutines still needs a manual check.

## Limits

- Channel producer/consumer checks work on the channel expression read from
  the source line, within one snapshot.
- Lock ordering, contexts never cancelled, timers never stopped and worker
  pool saturation are not detected yet.
