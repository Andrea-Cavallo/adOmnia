# adOmnia 1.0.9 — MCP guide, Nothing-style studios and a working load test

20 October 2026.

## Highlights

- **Talk to adOmnia from Claude.** `adomnia mcp` is a local MCP server over stdio (collections and mock server, nothing leaves your machine). The README now shows how to register it in Claude Code, Claude Desktop and Cursor, and lists the tools: `collection_list_requests`, `collection_run`, `mock_start`, `mock_stop`, `mock_status`, `mock_hits`, `mock_clear_hits`.
- **Load test you can actually use.** The test used to send nothing in request-count mode. It now works, and adds two quick probes: **Parallel** (N requests at the same instant) and **Repeat with gap** (e.g. the same request twice, 200 ms apart), with a waterfall that shows when each request left, how long it took and what came back. Unresolved `{{variables}}` in the URL are flagged and total failures show their cause.
- **Database Studio gets room.** Connections collapse into a slim rail, and fold away on their own once connected, so the database explorer and the editor take the whole width.
- **Hub pixel-art logo.** Choose it in Customize → Hub logo; it follows every palette.

## Design

Connections, Load test and the Code Studio Go panel now share the dot-matrix look of Security Center, and Utils and Log Inspector use a common studio header.

## Fixes

- Load test: no request was sent in count mode; warmup larger than the request count produced an all-zero report; responses under 1 ms were reported as 0.0 ms.
- Ctrl+B no longer hides the API collections across restarts and only works on the collections rail.

## Verification

TypeScript, the production build, the startup budget, 2098 frontend tests and the Go suite pass. Visual acceptance of the new panels, the Database rail and the Hub pixel logo is manual (see `mds/MANUAL-CHECK.md`).
