# v0.9.28 — Stable Git commit graph scrolling

- Fixed the Git Sync commit graph losing visual continuity after scrolling down
  through history and returning upward.
- The graph now keeps all currently loaded commit rows mounted, so branch lanes
  and parent connections remain stable throughout a scroll round-trip.
- History still loads incrementally near the bottom; only the fragile DOM-row
  virtualization was removed.

Validation: targeted Git graph regression tests, TypeScript check, and production
frontend build. The full Go suite was attempted, but an existing Windows-only
`internal/git` cherry-pick integration test timed out outside this frontend fix.
