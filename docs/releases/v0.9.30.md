# v0.9.30 — a0, present only when useful

## Compact companion

- a0 now rests in the lower-right as a 48 × 48 px circular launcher, with no
  permanent pill or label. Hovering provides the accessible `Ask a0` hint.
- Opening the assistant hides the launcher, avoiding a duplicated mascot. The
  chat opens at 320 × 380 px and can be expanded for longer work.
- The 44 px header uses a 26 px avatar, an on-demand model menu, and only the
  expand and close controls.
- The first message is simply **“Ciao Andrea, cosa facciamo?”**. Flow and Docs
  starter prompts sit with it and disappear after the first user message.

## Connected AI only

- a0 is visible only after the user runs **Test connection** successfully in
  Settings → AI for the selected provider and model.
- The successful test timestamp and provider/model identity are stored locally
  in Settings. A provider/model change, or a failed connection test, hides the
  companion until that configuration is tested again.
- This does not contact a provider in the background. The test and every chat
  message remain explicit user actions.

## Motion

- Opening uses a short 8 px fade-in; a0 has a restrained greeting, idle blink,
  hover acknowledgement and thinking movement. It is still while the user
  types, and all custom motion is disabled when the system requests reduced
  motion.

## Validation

- a0 companion connection-state regression test.
- TypeScript and frontend production build.
