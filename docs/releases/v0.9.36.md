# v0.9.36 — Go Studio becomes a real Go IDE

Go Studio now opens, edits, understands, lints, runs and tests real Go
projects, with gopls language intelligence, GoLand-style menus and shortcuts.
Everything stays local and nothing runs until you trust the project.

## Projects and editing

- Open or create Go projects. Sessions and recent projects are restored across
  restarts, and removed folders are dropped.
- A Project Overview shows `go.work`, every module with its module path and any
  `.go` folders outside a module.
- The lazy project tree can show or hide heavy folders (`.git`, `vendor`,
  `node_modules`, build output).
- The Monaco editor uses tabs, atomic saves and Save/Discard/Cancel prompts
  for tabs, sessions and the app. External changes offer Reload, Keep mine or
  Compare. Quick Open is on Ctrl/Cmd+P.
- Tabs can be pinned, bulk-closed (Close Others, Close to the Right, Close
  All) and reopened with Ctrl/Cmd+Shift+T. Pinned tabs survive bulk closes.
- The editor splits right or down (Ctrl/Cmd+\). Both panes share the same file
  with independent cursor and scroll.
- The breadcrumb shows the path plus the type and function under the cursor.
- `.go` files carry a Go gopher icon.

## Language intelligence (gopls)

- gopls starts automatically for trusted projects. It uses the project's
  selected Go SDK, recovers from crashes with bounded restarts and stops
  without leaving processes behind.
- Unsaved buffers are synced as you type, so diagnostics and completion match
  what you see rather than what is on disk.
- Completion includes automatic imports. Hover, signature help, Go to
  Declaration (F12, Ctrl/Cmd+B), Type Declaration, Implementation
  (Ctrl/Cmd+Alt+B), Find Usages (Alt+F7) and Symbol in Workspace (Ctrl/Cmd+T)
  are all available.
- F12 navigates into Go SDK and module cache sources, which open read-only.
- Rename (F2 or Shift+F6) shows a multi-file preview before anything changes.
  Code actions and quick fixes open with Alt+Enter.
- Reformat Code and Optimize Imports can also run on save (on by default).
  gofumpt and staticcheck analyses are optional.
- A Structure pane lists the file's types, functions and methods. The status
  bar shows gopls state, workspace loading progress and error/warning counts.
- Stale requests are cancelled as you type. Late answers are never applied to
  newer text.

## Linting

- golangci-lint is preferred, with staticcheck as a fallback. Project config
  files are used when present and never created.
- Run Linter (Ctrl/Cmd+Alt+Shift+L) is cancellable and stops the whole process
  tree. Lint on save is optional.
- Findings appear in the gutter, Problems and status bar, labelled with their
  linter so they stay distinct from gopls diagnostics.

## Run, test and tools

- Build, Run, Stop and Restart work with structured arguments (no shell),
  stdin, ANSI output, clickable `file:line` links, exit code and duration.
- A ▶ in the gutter runs `func main`, or runs a single `Test`, `Benchmark`,
  `Fuzz` or `Example` function.
- Tool windows: Run, Problems (gopls + linter + build), Usages and Find in
  Files. Find in Files is cancellable, with case, whole-word, regex and
  include/exclude filters.
- Official Go toolchains can be installed and switched per project with
  checksum verification. Install actions for gopls, golangci-lint and
  staticcheck each ask for explicit confirmation and show their output in the
  Run console.
- Tool Paths accepts custom gopls and linter binaries. Module dependencies are
  managed through previewed `go get` and `go mod tidy`.

## Menus and shortcuts

- A full menu bar (File, Edit, View, Navigate, Code, Go, Run, Help). Actions
  that are not available are disabled, and their tooltip explains why.
- Help → Keyboard Shortcuts lists every binding. Inside Go Studio,
  Ctrl/Cmd+W closes the editor tab instead of a hidden HTTP tab.

## Fixes

- Switching away from a read-only SDK file could overwrite another file's
  unsaved buffer. Editor changes are now bound to the file that actually
  changed.
- Stopping a process no longer races with its natural exit. The gopls status
  is final as soon as Stop returns.
- Cancelling a request no longer surfaces unhandled promise rejections.
- Decorative icons no longer change accessible names, and context menus widen
  to fit labels and shortcuts.

## Known limits

- Debugger, test runner tree, coverage, integrated terminal and multiple
  windows arrive in later phases. There is no Debug button until it is real.
- The native Wails window still needs a manual pass on Windows. All flows were
  verified end-to-end in the browser against the real Go backend.

## Verification

- 595 frontend tests across 130 files, TypeScript and the production build
  pass.
- `go vet` and `go test -race ./internal/goide/...` pass against real gopls
  v0.23.0, golangci-lint v2.14.0 and staticcheck 2026.2.1. The package
  cross-builds for Windows and macOS.
