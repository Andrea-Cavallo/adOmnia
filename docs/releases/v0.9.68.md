# adOmnia v0.9.68 — Chat understands the open file

Asking milk to read the open class previously sent only the question and project
folder. Chat now identifies the active file and attaches its live editor buffer,
including unsaved changes. Copilot uses the same preparation so source context
does not depend on whether its language server has already tracked the file.

Both chats attach a bounded project file index, filtered through the project's
AI exclusions. This is an index, not the contents of every file in the repository.
Missing or excluded editor files are identified explicitly instead of leaving
the model to guess. File contents and selections are bounded; the complete prompt
respects Copilot's 64 KiB transport limit, including multibyte text.

milk shows file and project switches and records the actual attachment labels
under the original question. Copilot's attachment choices survive detachment.
Detached milk receives active-file updates and forwards context choices to the
project window; that owner prepares the prompt from its own live document state.
The active selection can also be included when sending from the main editor.
milk slash commands continue to execute as commands without appended context.

Known secrets are redacted before sending. Sensitive paths and
`.adomnia/aiignore` are checked; `off` and `local-only` project policies block
ordinary milk/Copilot prompts because these integrations may use remote providers.
No request is sent merely by opening or detaching a chat.
