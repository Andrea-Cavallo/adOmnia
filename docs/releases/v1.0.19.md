# v1.0.19 — JavaScript debugging, docked Function Explorer, every tool from the Hub

Code Studio can now debug JavaScript and TypeScript, Function Explorer becomes a docked
tool window, the Home Hub reaches every adOmnia tool, and the Swagger Editor shows
responses defined through `$ref`. No project data format changes and no migration is needed.

## Code Studio

- **Debug JavaScript and TypeScript.** Debug project files and package-manager runs with
  js-debug, from a JS/TS run configuration or the Tools menu. js-debug is pinned to v1.140.0,
  verified by SHA-256 and installed only after you confirm the exact command.
- **Function Explorer is a docked tool window.** Call Hierarchy (`Ctrl+Alt+H`, or the
  *callers · callees* lens) opens it next to the editor instead of covering the IDE. Put it
  **Left** or **Right** from its header and drag the splitter to resize it; side and width
  are remembered. **Calls** shows callers and callees with a source preview; **Visual Graph**
  draws the same hierarchy. Text and spacing now match the rest of the IDE. The separate
  *Quick popup* is gone.
- **Symbol origin lens.** A declaration shows where it comes from (Go module path and package,
  Java package, or the JS/TS module path); click it to reveal the file in the project tree.
- **Clearer Find Usages.** Results are grouped by file with the real file icon, collapsible
  groups, the selected result highlighted, and the same source preview used by Function
  Explorer.
- **More tools from Code Studio.** The *Studios* menu lists every adOmnia tool that can open in
  its own window, grouped by category, and offers *Code Studio workspaces…*. The AI hub is a
  permanent tab in the side pane.

## Home Hub

- **Every tool is reachable from the Hub menu.** The left menu now lists the same categories as
  the main navigation rail: Code Studio, API Core, Protocols, Local Data, Document Studio,
  Power Tools, Security and Workspace. A category with one tool opens it directly; the others
  expand in place to show their tools. Tools hidden by your Lab/Advanced settings stay hidden.
  The redundant *Home* entry is removed.

## API Docs and Swagger Editor

- **Responses defined through `$ref` are complete** ([#228](https://github.com/Andrea-Cavallo/adOmnia/issues/228)).
  Reusable responses under `components.responses` (and chains of them) now show their
  description, content types, body schema, examples and headers, like inline responses.
  Referenced parameters, request bodies, headers and path items are resolved the same way.

## Appearance

- **New Static Citrine skin**, available in Settings → Appearance and as an exportable skin.

## Removed

- **The MCP client panel.** adOmnia no longer connects to external MCP servers from the UI.
  The local MCP **server** (`adomnia mcp`) is unchanged.

## For developers

- **Go module renamed** to `github.com/Andrea-Cavallo/adOmnia`, with package comments for
  pkg.go.dev. Code that imports adOmnia packages must update its import paths.
- **Standard MIT `LICENSE`**, third-party notices in `NOTICE.md`.
- **Code Studio internals** moved further into the language-agnostic IDE core (terminal,
  language server manager) and the Go adapter (Go tools); the Wails bindings are unchanged.
  The technical reference now opens with a diagram of how the pieces interact.
- Go 1.27 modernizers applied and enforced by lint; Go coverage is uploaded to Codecov.
