# adOmnia 0.9.62 - install and update milk from gO Studio

[milk](https://github.com/scoutme/milk) arrived in gO Studio with 0.9.61. This
release removes the last manual step: you no longer need a terminal to get it.

## Install / Update milk

- *milk settings* (gear in the milk chat, or the chat's empty screen) has an
  **Install milk** button, or **Update milk** when milk is already there.
- adOmnia asks the milk repository for its releases, takes the newest one that
  is v0.4.0 or later (the first with `milk serve --acp`, pre-releases included,
  since milk publishes only those) and downloads the binary for your platform.
- The download is checked against the SHA-256 that milk publishes next to it;
  a mismatch is refused and the existing milk is left untouched.
- The binary goes where milk's own installers put it:
  `%LOCALAPPDATA%\milk\bin\milk.exe` on Windows, `~/.local/bin/milk` on macOS
  and Linux. If an older milk elsewhere on `PATH` would win, adOmnia remembers
  the new path. milk is then enabled and started.
- The connection follows *Settings → Network & Privacy* (proxy, corporate CA,
  offline mode) and appears in the network activity log.

Every time milk ships a new release, **Update milk** brings it in: adOmnia never
bundles its own copy.

## Fixed

- A milk older than v0.4.0 used to fail with "milk process is not available"
  (the log said `unknown flag: --acp`). gO Studio now reads `milk --version`
  first and says *milk v0.0.3 is too old: gO Studio needs v0.4.0 or later*, with
  the Update button one click away.
