# v0.9.34 — a0 knows the product and can build mocks

## A real product model

- a0 now consults a compact **capability map** describing every adOmnia tool —
  HTTP collections, Mock Server, Broker Studio, Database Studio, MCP, the
  browser/HAR debuggers, Log Inspector, developer utilities and more.
- The assistant reasons about the product that actually exists instead of
  inventing generic API-tool features. It cannot claim a capability that is not
  in the map.
- For each request, the prompt includes the capabilities most relevant to the
  user's wording, so a0 routes answers to the right tool.

## Mock generation

- With **Agent actions** enabled, a0 can generate local **Mock Server**
  endpoints from a natural-language description such as "Mockami una API REST
  per una todo list" or "Create a mock API for invoices".
- Generated endpoints are converted into the same reviewed, persisted shape the
  Mock UI uses: validated path, method, status code, headers, body and bounded
  delay. The result opens in Mock Server for review.
- Italian and English commands have a deterministic local fast path, so the
  action still succeeds when a provider does not follow the structured JSON
  schema. Negative commands such as "non mockare" are ignored.

## Navigation actions

- a0 can return a validated `open-panel` action to open or switch to a specific
  tool, using an exact panel id from the capability map. Unknown panels are
  discarded.

## Multilingual conversation

- a0 now replies in the same language as the user instead of forcing English.
  Italian follow-ups and confirmations are answered in Italian.

## Conversation context

- A bounded slice of the recent conversation is included in the prompt so
  follow-up requests ("Ora mockala") stay coherent without unbounded context.

## Safety

- All new action types are validated and bounded before they touch the local
  workspace: three actions at most, bounded descriptions, safe methods, paths
  and status codes. Credentials remain excluded from the action protocol.

## Also in this release

- **Leaner startup:** the fresh Hub loads about 30.5% less initial JavaScript,
  deferring the sidebar, command palette, AI assistant, import parsers and
  closed editors. A CI startup budget prevents optional tools returning to the
  entry graph.
- **Bundled game extracted:** a0: Bug Hunt is now a separate local project; its
  source, tests and artwork are preserved outside adOmnia. Workspace data and
  settings are unchanged.

- `go build ./...` and the complete `go test ./...` suite pass.
- The Mock generation and open-panel flows were checked in the local
