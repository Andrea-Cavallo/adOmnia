# adOmnia v1.0.22

## AI chat

- **Local LLM chat with Ollama.** The local chat can start `ollama serve` and download a model with progress, without leaving Code Studio.
- **Pi agent** joins Claude Code and the other coding agents in the AI chat; `MIMO_API_KEY` is accepted as an alias of `XIAOMI_API_KEY`.
- **Redesigned chat panels.** One shared header with a provider switcher (power toggle included) and a tasks button replaces the row of provider tabs; Copilot, agent and local LLM chats render inside it.
- **ACP compatibility.** Object-shaped session capabilities (claude-agent-acp ≥ 0.89) are accepted, and startup failures keep the protocol error.

## Other changes

- **Security audit skill.** A new Security Center tab runs Cloudflare's security-audit skill with the coding agent chosen in the AI chat, as an Agent Task with shared permissions and stop. The skill is installed on request at a pinned commit.
- **Certificates open decoded in Code Studio.** `.pem`, `.crt`, `.cer` and `.key` files show certificates and key metadata (never the key itself); *Decrypt…* hands an encrypted key to the Power Tools encryptor.
- **Flows:** delete canvas blocks from the context menu.
- **Network tools:** process observers use native Windows TCP snapshots.
- Lint cleanups (golangci-lint, semgrep, oxlint) and a CI fix for the SDK detection test.

## Verification

- CI on `main` (lint, Go and frontend suites, builds) is the release gate.
- Native acceptance of the Ollama start/pull flow and the security-audit tab remains a manual check.
