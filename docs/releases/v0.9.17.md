# adOmnia 0.9.17 - A beatable final boss, built platforms, and a full dependency sweep

## The fix that matters

**The Legacy Monolith could not be defeated in 0.9.16.** One arena slab sat directly above the core, and damaging the core means falling onto it — the slab caught every attempt. The slab now sits beside the core, where it still works as a launch pad but leaves the drop clear.

A regression test came with the fix: no platform may overlap the core's x range within 170 px above it. It was verified to fail on the old geometry before being accepted.

## Bug Hunt

**Platforms are built, not drawn as rectangles.** Every slab is a chassis now: a lit rail that reads as the standing surface, end caps, etched circuit traces, and a recessed glyph window that names the slab's role — `>>>` ground, `</>` floating, `<   >` moving, `/ / /` unstable, switching to `! ! !` as it gives way. The neon accent follows the role, so the rule is read before it is felt.

Ground slabs sit on a real substructure — vent bays with live status lights, seam bolts, pylons and slack cabling — so the floor has mass instead of hanging in the dark. Floating slabs carry pulsing anti-gravity mounts, and the arena ceiling reuses the same slab flipped, rail facing down.

**A start menu that explains itself.** The dense mission paragraph is gone, replaced by three readable blocks: the goal, a controls grid with real key caps, and a LIVES panel that states what a death costs. The HUD pill now reads `LIVES ♥♥♥ 3` instead of three bare glyphs and turns red on the last life.

## Dependencies

Every direct Go module and every npm package moved to its current release: `wails/v3` and `@wailsio/runtime` to 3.0.0-beta.23 (together, since the IPC layer requires them locked), `golang.org/x/crypto` 0.57.0, `golang.org/x/net` 0.59.0, `grpc` 1.84.0, `nats.go` 1.54.0, `klauspost/compress` 1.20.0, `modernc.org/libc` 1.77.0, `goja` and others; `vite` 8.3.0, `vitest` 5.0.1, `postcss` 8.5.28, `lucide-react` 1.47.0, `yaml` 2.9.1.

Two updates are deliberately not taken:

- **mermaid 12.0.0** stays on 11.17.2. It pulls `chevrotain` → `lodash-es` with five high-severity advisories (code injection via `_.template`, prototype pollution in `_.unset` and `_.omit`). 11.17.2 keeps `npm audit` at zero.
- **`digitorus/pkcs7` and `digitorus/timestamp`** stay pinned. Their current releases require Go 1.27 while this project targets Go 1.26.5 — and they are why `go get -u ./...` refused the whole build list, so the direct modules were updated individually instead. Raising the toolchain floor affects CI and every contributor, and is a separate decision.

## Verification

`tsc --noEmit` clean, `npm run build` clean, **553 frontend tests across 113 files** (51 game tests), `go build ./...` and `go test ./...` passing, `npm audit` reporting no vulnerabilities.

The platforms and the menu were reviewed on screen in a real browser before release. That pass caught the floor going weightless once the rectangles were removed, which is why the ground substructure exists.
