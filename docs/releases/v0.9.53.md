# adOmnia v0.9.53

A cleaner window, a Hub that fits on one screen, a new Go Studio inspector for `context.Context`, and a fix for a confusing gopls error on startup.

## UI fixes

- **System title bar hidden by default.** On Windows and macOS adOmnia draws its own title bar again, including for users who had switched to the system bar after v0.9.49 (Settings v13 migrates that choice once; you can still pick *System* in Settings → Appearance). Linux keeps the system bar.
- **Detached Go Studio windows match the main window.** They open frameless and the Go Studio toolbar acts as the window bar, so every window has the same chrome.
- **The Hub fits on one screen.** The hero and the studio cards share the viewport height: all six studios are visible without scrolling.

## Go Studio

- **Context Propagation Inspector** (*View → Context Propagation Inspector*, Alt+9). Static analysis of `context.Context` in the current file, saved or not, with editor markers. It flags:
  - `context.Background()`/`TODO()` inside a call chain;
  - timeouts that are missing or too wide (threshold configurable);
  - context stored in structs and leaked `cancel` funcs;
  - ignored cancellation, broken chains and trace-ID propagation.

  It works offline. The checks are conservative heuristics: they point at suspicious patterns, not certain bugs.
- **No more "Error loading workspace folders … addView called before server initialized".** A file opened while gopls was still starting reached it too early. Documents now wait for the gopls handshake and are sent right after it.
