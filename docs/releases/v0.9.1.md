# adOmnia 0.9.1 — Log Inspector

Log Inspector turns long application and OpenShift pod logs into structured,
navigable events without sending their contents outside the computer.

## A dedicated Power Tools destination

The **TOOLS** menu now contains exactly **JSON Studio**, **Log Inspector** and
**Tool Launcher**, in that order. Log Inspector opens directly in its own
full-size workspace and no longer appears among the launcher utilities. The
command palette also opens this dedicated destination.

## Read and normalize real logs

Paste logs, type them in the editor, drop a file or open a local text file.
Content detection supports single JSON objects, arrays, JSONL/NDJSON, plain or
mixed text, OpenShift/CRI-O prefixes, ANSI terminal output, escaped nested JSON,
Java exceptions and Go panic stacks.

Malformed lines remain visible as marked `RAW` events without stopping the
import. Common timestamp, level, service, Kubernetes and correlation fields are
normalized across typical aliases.

## Investigate and correlate

- Virtualized compact event list with configurable columns and density.
- Full-text and field queries, level filters, facets and time ranges.
- JSON tree, complete message, numbered stack trace, context and raw source views.
- Chronological correlation by correlation ID, trace ID or request ID, including
  service transitions, errors and inter-event timing.
- Local saved queries, sensitive-field masking and filtered JSON, JSONL or text export.

Parsing runs in a Web Worker with progressive results, cancellation and
configurable retention limits. Everything remains local; no log content is sent
to a service and no telemetry is added.

## Known limitations

Direct `oc logs` execution, live tailing and compressed archive import remain
planned. Files from `oc logs` can already be pasted or opened directly.
