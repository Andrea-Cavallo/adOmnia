# v0.9.29 — Faster workspace requests and a cleaner sidebar

## Highlights

- Right-click the active workspace header and select **New Request** to open a
  blank request immediately.
- New requests created from the workspace or Collections controls now appear at
  the root of the sidebar, before all user collections. They are stored locally
  with the active workspace and can still be renamed, exported, deleted or moved
  into a collection when they become part of a larger API.
- Workspace, Environment and Hosts now share a single compact sidebar row. Each
  remains independently selectable, with creation and management actions in its
  respective menu; Collections gains the reclaimed vertical space.

## a0 companion

- When AI is explicitly enabled in Settings, a0 appears in the lower-right as a
  small expandable chat companion with happy, thinking and concerned expressions.
- It receives a deliberately minimal workspace outline (request names, methods,
  URLs and active header names); header values, environment values and secrets are
  not sent as chat context.
- Ask it to outline a Flow, generate API docs, explain a collection, or propose
  headers. Flow and Docs open their established adOmnia workflows. Header changes
  are shown first and are only added after clicking **Apply to open request**;
  they remain unsaved until the normal request save action is used.

## Reliability and packaging

- Restored tabs with an old incomplete shape are repaired before rendering, so a
  stale saved session cannot trigger the recovery screen.
- Windows build metadata is rendered before Wails generates the `.syso` resource,
  so Explorer shows the real product description and version.
- Wails and `@wailsio/runtime` move together to `3.0.0-beta.25`; Sarama and Bart
  are updated to their compatible releases.

## Appearance

- Added the optional **Brick Workshop** skin: a tactile workshop-inspired look
  that can be selected from Themes without altering the default theme.

## Validation

- Frontend production build and TypeScript check.
- Frontend test suite.
- Go build and package metadata regression test.
