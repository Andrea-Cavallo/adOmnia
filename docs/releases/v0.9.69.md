# adOmnia v0.9.69 — Coherent design and personal palettes

The Hub is now an editorial landing surface instead of a bare list: it uses the
same theme tokens as the rest of the app, shows real workspace and request
activity, and pairs metallic studio icons with a gO Studio entry. Dark and White
share one neutral surface hierarchy, primary-action and text/border tokens, so
every panel reads as the same application. The footer exposes only Dark and
White; the API response waiting and loading views use a compact layout without
the logo.

A personal accent colour is saved locally. Appearance settings offer presets, a
colour picker and HEX input; the choice updates shared UI tokens, the brand mark,
Monaco selections and terminal cursors immediately in both modes, and reset
restores the theme palette. Derived colours keep text and actions readable while
semantic status and syntax colours stay distinct.

IDE plugin contributions are now honoured: enabled plugins integrate commands,
code actions, analyzers, project templates, language-server lifecycle and
Developer Context adapters through the existing sandbox and trust controls.
Pod logs resolve Go file locations against the explicitly selected local
project; ambiguous paths remain plain text.
