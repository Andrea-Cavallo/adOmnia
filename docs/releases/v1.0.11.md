# v1.0.11 — Code Studio header, safe saves and additional languages

- Compact Code Studio header and file tabs with theme-aware Run/Debug controls, official branding, and New file action.
- Save highlights unsaved changes in the active document. An asynchronous save retains later typing, updates recovery and rejects duplicate writes.
- Search Everywhere uses Ctrl/Cmd+K; Commit uses Ctrl/Cmd+Shift+K. Secondary toolbar actions remain available at narrow widths.
- Chinese, Japanese and Russian settings/navigation/UI catalogs, loaded only when selected to preserve the startup budget.
- Animated README introduction and mock-server startup race fix.
- Includes the previously prepared v1.0.10 Installer, MCP and Java improvements documented in [v1.0.10](v1.0.10.md).

## Validation boundaries

Full frontend and Go suites, build/type checks and startup budget are checked for this release. Native visual acceptance of the new header, live palette changes and desktop Save workflows remain open; the component browser preview does not prove native Wails behavior. macOS/Linux packaging is performed by release CI.
