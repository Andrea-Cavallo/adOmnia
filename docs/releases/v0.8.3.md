# adOmnia 0.8.3 — Usable API flows and reliable recording

Record an API journey, reuse response data in the next request, and replay it from a clearer, adjustable workspace.

## Flow workspace

- Compact nodes and stronger directional arrows make execution order and branches easier to follow. Arrange preserves conditions and branches; saved positions survive reopening.
- Drag nodes freely, hold **Shift** to snap to the grid, and drag the canvas background to pan. **Ctrl + scroll** zooms around the cursor; **F** fits the flow, **0** resets zoom, and **+ / −** adjust it.
- Inspector, execution timeline, Mermaid import and AI panels support closing, floating, dragging, resizing, maximizing and docking. Inspector and timeline can be reopened from the toolbar; focus mode temporarily hides panels.
- Closing the inspector preserves the selected step. Running a flow does not reopen panels the user closed.
- Saved flows are available from a compact header switcher, with import/export and layout actions in the toolbar menu.

## Recording and replay fixes

- The recording save dialog now includes Italian translations for mapping guidance, call counts and save/discard actions.
- Fixed `unknown storage bucket "flows"` when saving a recording. The naming dialog stays open when its name is cleared and prevents duplicate saves.
- During recording, an exact, unambiguous JSON response value copied into a later request becomes an extraction and a variable reference. This covers JSON bodies, parameters and bearer tokens; the save preview shows the inferred mappings.
- Existing variable references are linked when their current environment value uniquely matches a recorded response field. Replay can then obtain a fresh ID or token instead of retaining the original value.
- JSON substitutions escape string values correctly and preserve unquoted numbers, objects and arrays. Extraction paths support nested objects and array indexes.
- Transport errors appear in the execution timeline, stop-on-failure halts subsequent linear steps, cancellation stops retries, and replay does not record itself.
- Fixed status assertions using `>=` / `<=`, failure-terminal detection, and the local Mock Commerce demo startup/status checks.

## Compatibility and maintenance

- Existing saved flows remain compatible. The local `flows` bucket is created automatically; no manual database migration is needed.
- Raw response bodies used for inference remain in memory during recording. Persisted request snapshots retain credential redaction. Ambiguous matches remain literal and can be mapped manually.
- Includes the dependency updates since v0.8.2 for Go libraries, Mermaid, PDF.js, Lucide and Vite. Desktop and npm version metadata are aligned to 0.8.3.
