# adOmnia v0.9.51

Go Studio is faster to open on real corporate machines, easier to read in daylight, and better at preserving project context.

## Highlights

- **Light or dark in one click.** Two compact controls in the IDE status bar switch directly between the built-in light and dark themes.
- **Apple-inspired light IDE.** The light skin uses cool-white surfaces, subtle blue-grey separators, rounded editor islands and soft elevation based on the supplied reference.
- **Hub light artwork restored.** a0's light scene is selected directly by application state and no longer disappears because of CSS selector conflicts.
- **Instant Go detection on VPN/proxy PCs.** SDK discovery reads local metadata first, caches tool versions and prevents implicit toolchain downloads with `GOTOOLCHAIN=local` unless the user explicitly chose otherwise.
- **Project context survives restarts and moves.** Terminal tabs restore their name, shell and project-relative folder; crash-recovery snapshots follow renamed projects through their module identity.

## IDE additions

- Dependency Graph with transitive version chains, duplicate-version evidence, license/weight/package badges, updates and on-demand vulnerability scanning.
- Runtime Enrichment overlay for routes, files, datasources, topics, latency, errors and dynamic request edges observed by the local Live Development Session.
- Change Signature powered by `gopls`, with a preview before declaration and call sites change.
- Three-way merge editor with per-conflict Ours, Theirs, Both and Base actions.
- Toolchain and tool-version caching that keeps repeated settings/status checks responsive.

## Reliability

- Buffer-recovery events are safe in headless environments, so the full frontend test suite does not leak asynchronous `document is not defined` failures.
- DOMPurify and `fast-uri` are updated to patched releases; the production dependency audit reports zero vulnerabilities.
- No project command, terminal or tool starts automatically in an untrusted workspace.
- Runtime evidence remains local; the release adds no telemetry or cloud dependency.

## Verification

- `npm audit --omit=dev` reports zero vulnerabilities.
