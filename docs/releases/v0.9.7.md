# adOmnia 0.9.7 - Log Inspector reliability pass

This is the public release for the Log Inspector reliability pass. It includes
the analyzer improvements prepared after `v0.9.4`, plus a Linux CI packaging
fix for GitHub runners affected by the external Google Chrome apt mirror.

## What changed for debugging

- Request analysis now groups by correlation ID, trace ID or request ID, so logs
  that only carry a trace ID still appear in the request summary.
- A timeout followed by retry and a final 2xx response is shown as a successful
  request with retry evidence, while timeout plus missing/5xx final response
  remains a timeout.
- Durations distinguish explicit request duration from an observed log window.
  Estimated windows are marked with `~` in the overview.
- Request/response payload detection now includes `attributes.http.request.body`,
  `attributes.http.response.body`, direct `attributes.request/response` objects
  and JSON strings that need unwrapping in the detail view.
- Multi-file imports keep a stable `sourceId`, readable `sourceName`, and
  distinguish homonymous files such as `app.log #1` and `app.log #2`.
- JSON/JSONL export includes `sourceId` and `sourceName`, so evidence bundles
  retain file provenance after filtering.
- The source filter accepts both `source:` and `sourceName:` from UI actions.
- The request/response tab now falls back cleanly when the selected event has no
  payload, instead of leaving the user on an empty disabled view.
- The multi-source parser avoids spreading large arrays into `events.push`, and
  file picker loading is sequential so cancellation has a chance between files.
- Diagnostic messages avoid claiming a 10s configured deadline when the log only
  proves that observed latency exceeded 10s.

## Structure and maintainability

`LogInspectorPanel.tsx` was split into smaller files:

| File | Responsibility |
|---|---|
| `useLogImport.ts` | Sources, background parse, progress, cancellation, field discovery and import errors. |
| `LogInspectorToolbar.tsx` | Toolbar and popovers for columns, sensitive fields and export. |
| `StatusBars.tsx` | Import progress, error banner and summary bar. |
| `toolbarControls.tsx` | Shared toolbar primitives. |
| `prefs.ts` | Persisted panel preferences and `usePrefs`. |

The panel is now a composition layer for derived data, shortcuts and layout.

## CI

- Linux GitHub runners now remove preinstalled Google apt sources before
  `apt-get update`. The project does not need Chrome to build Wails artifacts,
  and this avoids transient `Hash Sum mismatch` failures from that mirror.
