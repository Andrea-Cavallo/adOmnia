# adOmnia v0.9.58

adOmnia is meant to be used all at once: the code, the API that calls it, the database it writes to and the messages it sends. This release makes that physical. Any module can live in its own window next to the code. Go Studio adds a Security panel for dependencies and code, starts the whole local environment with one command, and reads profiles straight from a running service.

## Modules in their own windows

- **One click.** The ⧉ button in a panel's header opens that module in its own native window: API Workspace, Database Studio, Broker Studio, Mock Server, Docker Lab, gRPC, WebSocket and the other studios. Put the code on one monitor and the API or the database on the other.
- **One window edits a module.** While a module is detached, the main window shows *Show window* and *Bring back here* instead of a second copy, so the two windows never overwrite each other.
- **Nothing is lost on the way.** Pending saves are written before the window opens, and the main window re-reads the API workspace from disk when it comes back. Closing the window also brings the module back.
- **What stays in the main window.** The Hub, Settings and Go Studio. Go Studio projects already move with *File → Open Project in New Window*.

## Security Studio in Go Studio

- **Dependencies (govulncheck).** *View → Vulnerabilities* (or **Vulns** in the status bar) scans the module on demand. Findings are ranked by reachability: called by your code first, then imported, then only required.
- **Everything needed to decide.** Each finding shows:
  - advisory details and CVE/GHSA aliases;
  - the found and the fixed version, and the vulnerable symbols;
  - up to five call paths from your code to the vulnerable symbol, every step clickable (dependencies and the standard library open read-only);
  - the module dependency path.
- **Fix it.** An upgrade preview shows the `go.mod` change and runs `go get module@fixed` only after you confirm. Findings export as Markdown for an AI assistant.
- **Code, offline.** The *Code* view finds:
  - hardcoded secrets and committed private keys (masked);
  - disabled TLS verification, old TLS versions, weak crypto and short RSA keys;
  - plain HTTP;
  - SQL and shell commands built from strings;
  - path traversal and zip slip;
  - gob decoding of untrusted input, unbounded request bodies and world-writable permissions.
- **Built for legacy projects.** Every suppression needs a written reason, in the panel or as `// adomnia:security-ignore <rule>: <reason>`. A versionable baseline in `.adomnia/security.json` hides existing debt.

## Start the whole environment

- **Start Workspace.** *Run → Start Workspace* finds the project's Compose files and Go `main` packages. It reuses or creates shared run configurations (services restart on save), groups them in a pinned "Start workspace" compound and starts it. It asks for every member's runtime secrets first.
- **Stop Workspace.** Stops every running process of the project, with a controlled Compose stop.
- **Still explicit.** Nothing starts without the command and a trusted project. Without a Compose stack or a service, the compound opens for manual setup.

## Performance Studio

- **Profiles from a running service.** *From service* downloads goroutine, heap, allocation, CPU (1–60 s), block, mutex or thread-creation profiles from `/debug/pprof` of a service on this machine. It checks that the file is a real pprof and opens it. Localhost only, trusted projects only.
- **Call graph.** The most expensive functions as a layered caller → callee graph, with edge thickness by cost and colours by code origin.
- **Line cost in the editor.** Hot lines get a heat bar in the gutter and their cost at the end of the line. *Cost in editor* turns it off.

## Editor and Hub

- **Colour-coded comments.** `TODO`/`HACK`/`XXX` in amber, `FIXME`/`BUG`/`!` in red, `NOTE`/`INFO`/`?` in blue, `* important` in the accent colour. Works for `//` comments and for `#` comments in YAML, shell, Makefile and Dockerfile, and follows the theme.
- **A cleaner Hub.** It fits on one screen down to 1280×720, with a language-neutral **cO Studio** card, new key art in dark, light and sketch, and the generic `</>` studio icon in the rail.

## Fixes

- **Dependency Graph vulnerability badges.** They always came back empty, because the old parser read govulncheck's JSON stream as a single object. Both views now read the stream, verified against real govulncheck output.
