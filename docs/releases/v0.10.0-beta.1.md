# adOmnia v0.10.0-beta.1

First release in the stabilization cycle toward v1.0.0. This is a prerelease, not a declaration of desktop or multi-machine acceptance.

- API response errors use a dot-matrix title, dotted symbol and palette-aware detail frame.
- Request, Response and Send follow the selected accent color.
- Go Studio workspace startup supports ordered container readiness, migration and seed tasks before services, with failure stopping subsequent stages.
- The release scope and remaining acceptance gates are recorded in [V1-CHECKLIST](../V1-CHECKLIST.md).

Advanced collaboration remains future work; LAN collaboration requires the outstanding desktop and two-machine checks in the collaboration roadmap. Historical release notes remain available in the repository after retirement of older remote tags/releases.
