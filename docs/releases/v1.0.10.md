# adOmnia 1.0.10 — one Installer, a real MCP server and a Java studio that holds up on big projects

20 October 2026.

## Highlights

- **One Installer for everything adOmnia downloads.** *Tools → Installer…* lists every language server, linter, debugger and security tool in one dialog: gopls, the web servers, Eclipse JDT LS, golangci-lint, staticcheck, Delve, govulncheck, Strix, goimports, mockgen and stringer. See what is installed, tick what you want (or *Select all missing*) and confirm the exact commands once. Output goes to the Run console, never into your project.
- **Low resources, your way.** Choose what Low-Resource Mode pauses: AI assistants, optional analyses, completion, navigation or hover documentation. Change the choice while it is on and it is applied immediately; it survives a restart.
- **A much more capable MCP server and client.** `adomnia mcp` now exposes collection requests and environments as resources, three ready-made prompts, two new tools (`collection_get_request`, `collection_list_environments`), tool hints for auto-approval and standard JSON-RPC errors. Passwords, tokens, API keys and `Authorization` headers are masked in everything it returns. The MCP panel (client) now speaks Streamable HTTP with sessions and event streams, follows paginated lists, reads resources, keeps image/audio/resource results and reports why a stdio server died.
- **Java and Spring on multimodule projects.** The required Java version is read from every module, the suggested JDK is the one that really compiles, and Run, Debug and Test use the same JDK. Eclipse JDT LS starts with the project, before you open a file. The Run console renders Maven output like a terminal (progress redraws, aligned columns, no broken lines) and stays responsive during long test runs.
- **Friendlier Git.** A failed pull now explains what happened and offers the right way out (stash and retry, resolve conflicts, or abort) instead of a raw Git error.

## Also in this release

- Terminal appearance: presets, font, line height, cursor style and scrollback, with a themed terminal that follows the app palette.
- Nothing-style dialogs and toolbar selects across Code Studio.
- Language-server diagnostics are batched during a project import, so the editor no longer stutters while a big reactor loads.
- Maven goals can be run from any folder with a `pom.xml`, using the reactor wrapper when there is one.

## Fixes

- Stopping a long Maven or Gradle run now stops the whole process tree and keeps the last lines of output.
- The MCP client no longer mixes up answers when several calls run at once, and a crashed server shows as *crashed* with the end of its stderr.

## Verification

Go vet and the full Go suite, TypeScript, the full frontend suite (425 files, 2125 tests), the production build and the startup budget pass. The Java items were checked by hand in the app on a ten-module Quarkus reactor (JS-17.M1–M4 in `mds/MANUAL-CHECK.md`); the Installer and the per-service Low-Resource checks (INST-1) are still manual.
