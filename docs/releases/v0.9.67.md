# adOmnia v0.9.67 — Modular workspace and stable Git Sync navigation

adOmnia now includes a modular Go Studio workspace. Run output, Terminal,
service logs, Copilot Chat and milk can move left, right or bottom, maximize,
or detach into native windows. Detaching removes the view from the main IDE
and automatically expands the editor and remaining tools into the freed space.
Closing the child window or bringing the tool back restores its position.
Processes and conversations remain owned by the project. See
[the modular workspace guide](../architecture/modular-workspace.md) for the
implemented scope, outstanding docking features and native smoke checks.

This release includes the remote-development, Kubernetes, plugin and
distribution changes documented in [v0.9.66](v0.9.66.md), as well as the
following navigation correction.

Opening Git Sync from the sidebar could display the recoverable UI error
`Cannot read properties of undefined (reading 'request')`. With no active tab
and no collection, two missing identifiers compared equal and the panel then
tried to read a request from the missing tab.

Git Sync now requires an existing request tab and collection before reading
the request. Closed active tabs and tool tabs are handled safely. Local data
and saved workspace formats are unchanged.

Two component regression tests reproduced the exact exception before the fix
and pass after it. The modular workspace, remote tools and plugin changes from
[v0.9.66](v0.9.66.md) remain included.
