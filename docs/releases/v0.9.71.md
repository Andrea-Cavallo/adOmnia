# adOmnia v0.9.71 — A Hub that knows your day

The Hub gets a new right column inspired by Nothing phones: a live dot-matrix
clock and a daily record of the requests you sent and the errors you hit.
The executable icon now matches the app, Database Studio resizes like every
other panel, and the rail puts Go Studio first.

## Hub: the Today column

- **Live clock:** a dot-matrix clock with the real local time, the date and
  your time zone (for example "Rome • CEST"). It follows the accent palette,
  so changing the color in Appearance or from the status bar recolors it
  immediately, in Dark and in White.
- **Today's requests:** every request you send is counted for the day, with
  errors counted separately (network failures and HTTP status 400 or higher).
  The count is stored on your machine, survives restarts and starts again from
  zero at midnight. It does not depend on how much history you keep or on the
  "save responses" setting. Clicking it opens Request History.
- **Workspace at a glance:** the active workspace with its open tabs and the
  time since your last request, plus an Open workspace button in the accent
  color.
- **Start something new:** open a project, create a request or add a database
  connection right below.
- **Move the window from anywhere at the top:** with the app titlebar enabled,
  the whole top strip of the Hub drags the window and a double-click maximizes
  it, even though no bar is drawn.

## The executable icon matches the app

The exe, launcher, Linux icons and running window icon now use the white
adOmnia mark on the dark tile, the same one you see in the taskbar and in the
app. Before, Explorer showed the neon gradient tile. The neon version is still
available as `assets/icons/icon-neon.ico` for custom shortcuts. Windows may
show the old icon for an existing file until its icon cache refreshes.

## Database Studio

- **Resizable columns:** the Connections column, the Favorites/History/Schema
  column, the MongoDB navigator and the editor/results split use the same drag
  handle as the rest of adOmnia and remember their size.
- **Driver logos:** SQLite, PostgreSQL, MySQL and MongoDB show their logos in
  the connection list and in the Database Type picker, readable in Dark and
  White.

## Navigation and appearance

- **Rail order:** Go Studio is first, then API Core. Browser Debug moves into
  Power Tools › Debugging.
- **Accent from the status bar:** right-click Dark or White in the bottom-right
  corner to pick the accent from presets, a color wheel or a HEX value.

## Fixes

- No more dark strip beside the rail in White: panels fade in without sliding.
- The request Scripts editor and the OpenAPI spec editor no longer force the
  dark editor theme on Go Studio in White.
- `build.ps1` and `build-linux.ps1` regenerate icons from the SVG mark; the
  plain `go build` fallback embeds the icon too.
- Two unused images are no longer shipped inside the executable.
- README screenshots refreshed.
