# v0.9.38 — Go Studio: Fix with AI and real file icons

Go Studio can now ask adOmnia's AI provider to fix Go errors, with a
reviewed preview. The project tree and every file list show real
technology icons.

## Fix with AI

- Errors and warnings get a "Fix with AI" quick fix in the lightbulb, with
  Alt+Enter and in the error hover's Quick Fix. The Problems window adds a
  Fix with AI button on each project problem.
- The action appears only when an AI provider is enabled and verified in
  Settings → AI (Claude, OpenAI, a local Ollama…), and it uses that
  provider. Code is sent only when you click.
- The request carries the file with the problem. For errors such as
  `undefined: logger.GetLoggerInstance`, it also carries the non-test files
  of that local package, so the AI can fix the call or add the missing
  function where it belongs.
- The answer may change only the files that were sent. It opens in the
  change preview with only the lines that change, then applies to all
  files or to none and can be undone. If the AI proposes nothing usable, or
  the provider fails, Go Studio says so.

## File icons

- Go sources keep the gopher, and test files get a green marker. `go.mod`
  and `go.work` show the Go logo, and `go.sum` shows it dimmed.
- Real brand icons for Dockerfile and compose files, `.gitignore`, GitHub
  workflows, `.env`, Makefile, OpenAPI/Swagger, `package.json`, Helm
  charts, Markdown, YAML, JSON, TOML, TypeScript/JavaScript, shell,
  Terraform and more. Files without a brand get a generic icon, never an
  invented logo.
- Icons are used in the project tree, tabs, split editor, Quick Open,
  Search Everywhere, Find in Files and Problems.
- Each logo uses its official colour only where it stays readable on the
  active theme; otherwise it takes the text colour.
- The 45 marks come from Simple Icons (CC0) through
  `scripts/generate-brand-icons.mjs`, instead of shipping the full set. AWS
  and Azure are not available because Simple Icons removed them at the
  brands' request.

## Verified

- 734 frontend tests across 162 files, TypeScript, the production build and
  the startup budget pass. Initial JavaScript is 584,053 bytes; icons and AI
  stay out of the startup bundle.
- Go-to-definition was checked against real gopls v0.23.0 on Windows.
  Ctrl+click on a symbol that does not exist, such as
  `logger.GetLoggerInstance` when the package does not declare it, has no
  target: fix it with Fix with AI.
