# v0.9.50 — Copilot Ask chat, extra Go tools and a unified assistant column

GitHub Copilot gains a per-project Ask chat, Go Studio learns to detect,
install and run more Go tools, and the a0 assistant joins Copilot in a single
closable right column instead of its old floating launcher.

## Copilot Ask chat

- **Ask chat** (*Tools → Open Copilot Chat*, or the sparkle on the right tool
  stripe) opens a per-project conversation backed by the official Copilot
  Language Server.
- Each message can carry the **current file**, the **live Monaco selection**
  and a **filtered workspace manifest**. Only the active buffer and an explicit
  selection include source text; workspace context is a bounded path manifest.
- The built-in secret exclusions and the project's `.adomnia/aiignore` are
  enforced before context reaches the language server — the renderer never
  supplies source text, so the secret boundary stays a single backend filter.
- Replies **stream** into the pane, **Stop** cancels the active JSON-RPC
  request, and **New Chat** destroys the server conversation. History is
  session-only and never written to the project.
- Chat resolves its model through `copilot/models` (`{}`) before the first turn
  and requires a valid model, so an empty model cache no longer mislabels or
  drops a turn.

## Extra Go tools

- *Go → Toolchains* also lists **govulncheck**, **goimports**, **mockgen** and
  **stringer**, plus any tool you add (binary name and, optionally, a
  `module@version` to install it).
- Each tool is found in adOmnia's tools folder, `GOBIN`, `GOPATH/bin` or the
  `PATH`. **Install…** runs `go install` with the project SDK after explicit
  confirmation; **Run…** runs the tool with your arguments in a project folder
  (never a shell), with output in the Run console. Running requires a trusted
  project.

## AI di a0 in the right column

- Copilot and **AI di a0** are separate choices in the same closable right
  tool window as Structure and Project. Each stripe button opens or closes the
  column.
- a0 uses the provider verified in *Settings → AI Engine* and keeps its
  existing API-workspace actions. The former global floating launcher and
  popup no longer exist.

## Settings and lifecycle

- **Settings** (*File → Settings…*, Ctrl+Alt+S) gathers every Go Studio
  preference in one searchable dialog: editor, save actions, gopls options,
  low-resource mode, plus links to keymap, toolchains, tool paths and Copilot.
- Copilot lifecycle hardening: workspace notifications are gated on server
  initialization; Copilot starts only with an active project; one active
  workspace per account/project.
