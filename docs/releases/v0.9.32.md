# v0.9.32 — smarter AI setup and native DeepSeek

## Native DeepSeek support

- DeepSeek is available as a first-class cloud provider throughout AI Engine,
  connection testing, model discovery and the a0 companion.
- adOmnia uses DeepSeek's official OpenAI-compatible API endpoint and offers
  curated V4 Pro and V4.1 Flash choices while still accepting a discovered
  model identifier.
- Provider-specific errors now identify DeepSeek alongside the existing cloud
  and local runtimes.

## Intelligent, local-first credentials

- Automatic setup first checks the process environment, then active and saved
  adOmnia Environments, Vault-backed variables and standard workspace dotenv
  files such as `.env.local`, `.env`, `.env.development*` and
  `.env.production*`.
- Only exact variable names for the selected provider are accepted. Disabled
  environment entries and unrelated text files are ignored.
- Resolved keys are passed only for the current request. The AI settings screen
  reports the credential source without displaying or persisting the secret.
- Explicit saved credentials remain the final encrypted-Vault fallback, keeping
  existing configurations backward compatible.

## A clearer AI Engine

- Settings → AI Engine now uses a responsive master-detail workspace: grouped
  cloud/local providers on the left and provider details on the right.
- Optimization presets, credential state, connection testing, model filtering,
  model refresh and selection are visible without navigating through stacked
  cards.
- Advanced provider controls stay available in a compact disclosure, while the
  persistent footer always shows the active provider/model pair and offers
  reliable Cancel and Save actions.

## A generic English a0

- The companion greets every user with a neutral English welcome rather than a
  hard-coded personal name.
- Its system instruction requires English responses and prevents it from
  assuming or inventing the user's identity.
- Local Bug Hunt intent still launches without contacting a provider and now
  confirms the action consistently in English.

- All 680 frontend tests pass across 131 test files.
- `go build ./...` and the complete `go test ./...` suite pass.
- The AI Engine was visually checked at desktop and narrow responsive widths.
