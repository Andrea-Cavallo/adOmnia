# adOmnia 0.9.61 - milk in gO Studio and a fuller Kubernetes Studio

## milk: the AI chat that picks the right model

[**milk**](https://github.com/scoutme/milk) by Marco Cascianelli (MIT) is now an
AI chat in gO Studio, beside Copilot and a0. milk sends each prompt to a cheap
primary agent and hands off to a deep escalation agent only when the task needs
it, keeping the whole conversation across both. It brings its own tools, MCP
servers, workflows and memory.

- **Where:** the milk tab in the right side pane, the milk button on the tool
  stripe, or *Tools → Open milk*.
- **How it connects:** adOmnia starts `milk serve --acp` and talks the
  [Agent Client Protocol](https://agentclientprotocol.com) over stdin/stdout.
  One milk process serves every project; each project folder gets its own milk
  session, and *New chat* starts a fresh one.
- **Always up to date:** adOmnia does not bundle milk. It runs the milk you
  installed, found on `PATH`, in `%LOCALAPPDATA%\milk\bin` (Windows installer)
  or in `~/.local/bin` (macOS/Linux installer), or at a path you choose. When
  milk publishes a new version, update it from
  **https://github.com/scoutme/milk** and press *Restart* in *milk settings*:
  adOmnia uses it right away.
- **What you see:** the agent milk routed the turn to and why, every tool call
  with its status and output, the model's reasoning in a collapsible block kept
  apart from the answer, and milk's warnings (loops, consumption).
- **You stay in control:** milk asks before each tool call (Allow/Deny). A
  request left unanswered for 90 seconds is denied and disappears from the chat.
  *Approve every tool call without asking* is off by default.
- **Local-first:** agents, models and API keys stay in milk's own config
  (`~/.milk`); adOmnia stores only whether milk is enabled, the binary path and
  the permission choice. Stop cancels the turn inside milk too.
- **Resilient:** if milk crashes adOmnia restarts it with backoff and opens new
  sessions automatically; *milk settings → Show logs* shows its stderr.

### Install milk

```sh
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/scoutme/milk/main/install.sh | sh
```

```powershell
# Windows
irm https://raw.githubusercontent.com/scoutme/milk/main/install.ps1 | iex
```

Then configure at least one agent in milk (`milk`, then `/agent add`) and enable
milk in gO Studio's *milk settings*.

## Kubernetes Studio

- New tabs for **Deployments**, **Services**, **ConfigMaps** and **Secrets**.
  Secrets show key names and sizes only: values are dropped in the backend and
  never reach the UI.
- From a pod: **Exec** one-shot commands, **Files** download/upload (16 MB), and
  **Forward** a port. Services forward too. Forwards listen on 127.0.0.1 only,
  are listed live in *Port forwards* and stop with the app.
- Fixed: the context and namespace pickers showed `[object Object]`.
