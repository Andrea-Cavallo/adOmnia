# adOmnia v1.0.23

## Code Studio and Agent Tasks

- Isolated Git workspaces for agent tasks, verification evidence, bounded correction attempts, inline review comments, plans and explicit integration into the project.
- Acceptance scenarios, HTTP and headless-page verifications, and editable pull request drafts from collected evidence.
- Agent tool permissions by category and project-trust revocation that stops running tasks.
- Faster project opening, shared file indexes, incremental test updates, Git blame, clearer editor colors and additional framework route detection.
- Rust analyzer installation and additional detected run configurations and language setup workflows.

## Startup and resource use

- Load Monaco with the first opened file and optional skin styles when selected.
- Restore project units outside the startup path; defer Code Studio tools and avoid unnecessary language-server, Docker and Quick Open background work.
- WebView2 background networking and component updates disabled; the existing 512 MiB V8 heap budget remains a soft JavaScript heap limit.
- Resource recordings survive panel switches; exports include interval-weighted CPU values, sampling gaps, environment and optional UI context.
