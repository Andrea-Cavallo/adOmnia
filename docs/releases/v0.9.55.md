# adOmnia v0.9.55

One network policy for all of adOmnia, private Go modules that just work behind a corporate network, and a calmer Go Studio editor.

## Network and privacy

- **Offline mode for the whole app.** One switch in *Settings → Privacy & Data* blocks every connection adOmnia opens by itself to a non-local host: AI cloud providers, Copilot, update check, the vulnerability database, Go toolchain and module downloads, Git host APIs. Local models such as Ollama and the requests you send from the API client keep working.
- **One corporate proxy and CA bundle.** Set them once: the API client, AI providers, Copilot, Git and the Go toolchain all use them. TLS verification is never turned off, the CA is added to the system store. Project values still win.
- **Network activity.** A live, in-memory list of every connection adOmnia opened or blocked: category, host, path (never the query string) and result. adOmnia has no telemetry, and this list lets you check it.

## Private Go modules

- **Credentials through Git.** Add a token for each GOPRIVATE host or internal registry: it goes to the Git credential manager (Windows Credential Manager, Keychain, libsecret) and never to adOmnia files or back to the UI.
- **GOAUTH in one click.** Let `go` read registry credentials from Git (Go 1.24+).
- **Test module registry.** Probes the saved GOPROXY with proxy, CA and credentials, and explains login, TLS and proxy failures.

## Go Studio

- **Minimap removed.** The editor keeps the full width for code.
