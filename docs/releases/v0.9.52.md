# adOmnia v0.9.52

Go Studio protects more of your work, keeps secrets on your machine when you ask the AI for help, and makes logs readable at a glance.

## Highlights

- **Colour-coded logs.** The Run console colours each line by its log level (`log`, slog text/JSON, zap, zerolog, logrus), dims timestamps and highlights the level. Standard-library logs on stderr are no longer shown in red; compile errors and panics still are. Console and terminal use the bundled JetBrains Mono, and Log Inspector colours messages and marks error/warning rows.
- **AI that respects your secrets.** *Fix with AI* never sends files excluded by `.adomnia/aiignore` or known secret files (`.env`, keys, certificates). Tokens, keys and passwords inside code are replaced with placeholders before sending and restored in the proposed change. Git commit analysis and AI pull-request drafts send redacted diffs.
- **Apply only what you want.** The change preview has a checkbox per file and per change block.
- **Visual go.mod editor.** Module path, Go version, toolchain, `exclude` and `retract` from the Dependencies dialog, a `go mod tidy -diff` preview, and a per-dependency version list to upgrade or downgrade.
- **Crash recovery per project.** Unsaved buffers are stored per workspace in the local adOmnia store, so each snapshot rewrites only the project being edited. Existing recovery data migrates automatically.
- **Cleaner window and Hub.** The system title bar is hidden by default and the Hub fits on one screen.

## Also in this release

- Copilot Chat and a0 switch models directly from the chat.
- Database Studio and Broker Studio restore their tabs and active views.
- Debugger *Resolve wrapped errors* works even when the program never calls `Unwrap()`.
- Tool versions are cached across restarts.
