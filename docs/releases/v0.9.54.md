# adOmnia v0.9.54

Go Studio becomes a tool for teams and enterprise networks: flaky test detection, coverage and lint that focus on what you changed, a deeper debugger, offline and proxy-aware toolchains, per-project AI policy, and a cleaner, Apple-style editor.

## Tests and coverage

- **Flaky Test Detector.** Rerun a test or the whole run ×10/20/50/100 in random order. Each test shows failure rate and min/avg/max duration, and you can replay the exact order with the printed `-shuffle` seed. Possible causes are read from the output (data race, deadlock, timing, port conflict…), with a `-race` rerun and a GOMAXPROCS correlation (`-cpu=1,2,4,8`). Flaky tests are remembered per project.
- **Copy the reproducing command.** One click copies the `go test` command for a test, with filter, count, seed, race, tags and directory.
- **Test what you changed.** *Run → Test Changed and Dependent Packages* tests modified packages and every package that imports them.
- **Coverage that answers questions.** Patch coverage against a base branch, coverage by function in the Tests panel, and branch insights from the coverage profile.

## Code quality and lint

- **Lint only changed files**, a shared **lint baseline** in `.adomnia/lint-baseline.json` (only new findings show up), and **project linter settings** that open or create `.golangci.yml` / `staticcheck.conf`.
- **Custom analyzers as linter.** Any `go vet`-style binary runs as the project linter and its findings appear in Problems.
- **Code Quality dialog** with the top rules and files and a technical-debt trend.

## Commits and Git

- **Smarter commit dialog.** It lists changed symbols, marks the ones that touch HTTP, gRPC, database or brokers, flags breaking API changes, and runs pre-commit checks.
- **Line history.** *Git → Show History for Selection…* lists only the commits that changed the selected lines.

## Debugger

- **Disassembly and registers** for the paused frame, grouped by Go line.
- **Memory view.** A hex dump with ASCII from an address or an expression such as `&buf[0]`.

## Enterprise networks and privacy

- **Offline and air-gapped modes** for the Go toolchain (`GOPROXY=off`, `GOTOOLCHAIN=local`, optionally `GOSUMDB=off`).
- **Corporate proxy and CA bundle** for go, git and gopls, per project or global. A proxy password stays in memory only.
- **GOPRIVATE validation and guidance**, with a suggested pattern from the module path.
- **Per-project AI policy** in `.adomnia/ai-policy.json`: any provider, local models only, or off. Fix with AI and Copilot honour it.
- **Settings report** for privacy and audit, with secrets and home paths redacted.

## Large projects

- **Faster Find in Files.** On a 40-module, 4,000-file monorepo a search drops from about 3 s to 0.5 s on Windows. A scale test guards against regressions.
- **Workspace module graph** in *Module Dependencies* for multi-module projects and `go.work`.

## Look and feel

- **Finder-style folders** in the project tree, in light and dark themes.
- **Grouped Structure panel.** Constants, Variables, Types, Functions and Methods with counts. Methods sit under their type after the fields, functions show parameters and result, and symbols use GoLand-style letter badges.
- **Minimap on by default.** It fills the editor height with readable blocks and a soft view slider, so you can jump through long files. The inspection widget no longer covers it.
- **Cleaner Go Studio header.** A larger adOmnia logo, the project shown with its folder instead of initials, and a tidier branch widget.
