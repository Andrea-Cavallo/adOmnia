# adOmnia 0.9.0 — Log Inspector

Paste OpenShift pod output and turn compressed JSON, JSON Lines, mixed terminal text and multiline stack traces into searchable events without sending logs off the machine.

## Investigation workspace

- Open logs from the clipboard, editor, drag and drop, or any local text file. Format detection handles JSON objects and arrays, JSONL/NDJSON, CRI-prefixed OpenShift output, plain text, mixed prefix-plus-JSON lines and ANSI escape sequences.
- Common timestamp, severity, message, service, Kubernetes and tracing aliases are normalized while preserving raw input, original JSON, unknown fields, source line numbers and parse errors.
- Multiline Java exceptions and Go panics stay attached to the event that produced them. JSON strings in `message`, `body`, `payload` and `response` are decoded when possible.
- The central event list is compact and virtualized. Detail tabs cover overview, collapsible/searchable JSON, complete message, numbered stack trace and Kubernetes/tracing context.
- Wide layouts keep resizable filters, list and details visible. Narrow Power Tools panels use overlay filters and a focused detail view with a direct close action.

## Search, correlation and safe sharing

- Combine full-text search, field queries, level/time/stack/unparsed filters, include/exclude facets and a visual query builder. Matches are highlighted and preferred queries can be saved locally.
- Select a correlation ID, trace ID or request ID to rebuild its timeline chronologically, see elapsed deltas and errors, switch list/timeline mode or apply the identifier as a filter.
- Copy raw or filtered events and export JSON, JSONL or readable text. Sensitive-field masking covers authorization, tokens, cookies, passwords, secrets and custom field names. No logs leave the computer.
- Choose visible list columns and hide configurable noisy JSON fields without changing the original event.

## Large files and compatibility

- Parsing runs in a dedicated Web Worker and reports progressive batches without repeatedly cloning the full list. Import can be cancelled, rendering can be paused, and limits of 50k, 100k, 200k or 500k events are available.
- Filtering is deferred and the event list mounts only visible rows. Memory failures and truncation are reported explicitly.
- The acquisition boundary is ready for a future `oc logs` source. The OpenShift CLI binding and live streaming are intentionally not included in this release.

## Verification

Validated with the frontend production build, TypeScript, all 353 frontend tests across 72 files, `go test ./...`, diff checks and a live browser smoke test. The smoke test covered the mixed OpenShift sample, malformed-line retention, Java stack association, `level:error` filtering, request correlation, overlay filters and detail close behavior in a narrow Power Tools panel.
