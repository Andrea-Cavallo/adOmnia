# adOmnia v1.0.29

Legacy Java enterprise projects open, run, debug and test in Code Studio, and comments get their colors.

## Java enterprise legacy (the Eclipse Kepler gap)

- **Ant.** A `build.xml` without Maven or Gradle is a project: its public targets appear in Run (default first, grouped as Build, Test or Run) and its `main` classes run and debug with the classpath of the Java language server.
- **Servlets and `web.xml`.** A servlet with a URL (`@WebServlet` or a `<servlet-mapping>`) is a route, one per `doGet`/`doPost`/…, that opens the method. API Workspace, Mock, cURL and OpenAPI see WAR applications like Spring ones.
- **Tomcat and WildFly.** *Tomcat server* and *WildFly server* run configurations publish the exploded WAR in place from a private server folder (the installation is never modified), on the port and context path you choose. Debug starts the server with JDWP and attaches the Java debugger. Tomcat is found from `CATALINA_HOME`, a shared run configuration, the server runtime of the Eclipse workspace or the PATH.
- **Eclipse WTP projects.** Kepler Dynamic Web and EJB projects get their WTP containers (servlet and JSP APIs, `WEB-INF/lib`, dependent modules) resolved for the language server, so the editor stops reporting `javax.servlet` as missing.
- **JAX-WS and EJB.** `@WebService` endpoints are SOAP routes linked to their WSDL; the WSDL opens the class that serves it. `@MessageDriven` destinations are JMS topics; session beans and `@EJB` join the bean index.
- **JPA, JSP and EAR.** `persistence.xml` JDBC URLs are datasources (Oracle and SQL Server included), `@Entity` classes are tables, JSP pages are routes with HTML highlighting, and EAR context roots prefix the routes of their web modules.
- **Tests of Ant and Eclipse projects** fill the Test tree on the JUnit Console Launcher (JUnit 3, 4 and 5), installed once from the Java menu with a visible, confirmed command.

## Editor

- **Comment colors (Better Comments):** TODO, ALERT/FIXME, QUESTION, IMPORTANT and NOTE each have their own color, and `////` commented-out code is struck through, in line, block, Javadoc, SQL and markup comments.
- **Rainbow brackets** in every theme and HTML/XML tag names colored by depth.

## Dependencies and fixes

- CodeQL action 4.39.2, scram 1.3.0, oxlint 1.92.0, Tailwind 4.3.5 (one version in the build), Vite 8.3.6, Vitest 5.1.0.
- The tag colorizer no longer risks exponential backtracking on a hostile DOCTYPE.

## Known limits

Native acceptance in the desktop app (Tomcat/WildFly runs, WTP projects, Ant tests) remains manual. Not covered yet: JUnit Plug-in Tests for OSGi, JBoss 4–6 and WebLogic, Struts and Spring XML routes, EAR deployment, JSP language intelligence.
