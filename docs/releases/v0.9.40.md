# v0.9.40 — Go Studio: a maximised editor, compose, key encryption and a new look

Go Studio behaves more like a daily-driver IDE. Every pane closes on its own,
and the editor can take the whole window with one shortcut. docker compose
services run from the gutter, and collections and keys in the project flow
straight into the rest of adOmnia. Menus and dialogs have a modern design.

## Code first: maximise the editor

- **Maximize Editor** (*View*, Ctrl/Cmd+Shift+F12, or a double-click on an
  editor tab) closes Project, Structure and the bottom tool window, so the
  code gets all the space. Press it again to bring them back exactly as
  they were. This is JetBrains' *Hide All Tool Windows*.
- **Every pane closes completely** with its own — button or shortcut:
  - Project: Alt+1 (new);
  - Structure: Alt+7;
  - the bottom tool window (Run, Terminal, Tests, Problems…): Alt+4.
- **Maximize Go Studio** (the ⤢ button in the toolbar, now on
  Ctrl/Cmd+Shift+F11) also hides adOmnia's rail, the Go Studio header and
  adOmnia's status bar, so the IDE fills the window. Leaving Go Studio
  brings the rail back.

## docker compose from the gutter

- In `docker-compose*.yml` and `compose*.yaml`:
  - `services:` gets *Compose Up (all services)* and *Compose Down*;
  - every service gets *Compose Up 'service'*.
- `docker compose up` stays attached, so the logs stream to the Run
  console. **Stop runs `docker compose stop`** on the same services, because
  killing the client would leave the containers running.
- New *Docker Compose* run configuration type. It accepts only
  `up [services]` or `down`, never arbitrary flags.

## Everything is connected

- **Send to API Workspace.** Right-click a Postman, Insomnia, Bruno,
  OpenAPI or Swagger file in the project tree to import it into adOmnia's
  API Workspace, including unsaved changes. You stay in Go Studio, and a
  notice offers *Open API Workspace*.
- **Keys and certificates open in Power Tools.** Right-click a `.pem`,
  `.key`, `.crt` or `.cer` file and choose *Open in Power Tools: Inspect /
  Encrypt Key*. The PEM / JKS tool opens with the file loaded and inspected.
- **Encrypt private keys locally.** The PEM / JKS tool encrypts and decrypts
  private keys as standard encrypted PKCS#8 (PBKDF2-HMAC-SHA256, 600,000
  iterations, AES-256-CBC), with copy and download.
  - OpenSSL, Java and Go open the result with the same password; a test
    checks it with the real `openssl`.
  - Certificates in the same file stay unchanged, and nothing leaves the
    machine.
- **Recent projects in the toolbar.** The project menu lists the recent
  projects that are not open, and one click reopens them.

## A modern look

- **Menus.** Go Studio menus use a studio design: icons on every command
  (Run green, Debug blue, Stop red), check marks for toggles, rounded panels
  and shortcuts drawn as keycaps.
- **Dialogs.**
  - Confirmations show commands and paths in a structured, wrapped,
    monospaced section instead of one run-on paragraph.
  - Each dialog has an icon that says what it asks (command, question,
    deletion), a soft blurred backdrop and a spring entry.
  - For destructive actions, the focus starts on Cancel.
  - All Go Studio dialogs share the same backdrop and animation.
- **File icons.** Jenkinsfiles show the Jenkins emblem, and `.pem`, `.key`,
  `.p12`, `.pfx` and `.jks` show a key.
- **a0 stays out of the way.** The launcher in the bottom-right corner is
  invisible and click-through until the pointer comes near the corner, a0
  is thinking, or it gets keyboard focus.

## Lighter gopls

- gopls starts with `GOTELEMETRY=off`, so no telemetry process runs next
  to it, and with `GOMEMLIMIT=1GiB`, which trims memory peaks.
- Values you set yourself in the environment win.
