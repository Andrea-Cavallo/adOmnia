# adOmnia v1.0.32

Diagram Studio becomes a view of your code: generate a diagram from the project open in Code Studio, open a node's source beside it, and refresh it when the code changes. No v1.0.31 build was published, so this is also the first build with everything in [v1.0.31](v1.0.31.md).

## Diagram Studio linked to the code

- **Generate from Workspace.** Draws the project selected in Code Studio: services, endpoints, handlers, functions, topics, tables, OSGi bundles, flows and subflows. Five views of the same graph: System Architecture, Service Flow, Function / Call Flow, Endpoint Flow, OSGi / Legacy Flow. The analysis is local and read-only, and runs only for a project whose tools you authorized.
- **Open in Code Studio (Split Right).** Right-click a generated node: the diagram stays on the left, selected and zoomed as it was, and the file opens on the right at the definition. *Show in Diagram Studio* in the editor menu goes the other way.
- **Callers, callees and the other tools.** Grow the diagram one hop at a time; open an endpoint in the API Workspace, a table in Database Studio, a topic in Broker Studio; search for any entity.
- **Refresh from Code.** Keeps positions, sizes, labels, styles and everything you drew by hand; marks as stale a node whose entity disappeared.
- **Evidence is visible.** Connectors show whether a relation is declared, derived, inferred (dashed amber) or observed (animated).
- **MCP.** `diagram_workspace_overview` and `diagram_find_entity` let an agent read what the diagram is built from.

## Diagram Studio editor

- **Pages, legends, sticky notes, images**, quick fill colors and corner radii from the right-click menu.
- **Icon library.** 3,472 technology logos and 783 AWS architecture icons, with search and recently used icons.
- **UML sequence diagrams**, drawn by hand or from Mermaid-style text; double-click a crooked connector to straighten it.
- **draw.io and SVG** import and export; **From Markdown** generation, also through the `diagram_from_markdown`, `diagram_create` and `diagram_shapes` MCP tools.
- **Simpler selection toolbar.** Named buttons (Duplicate, Group, Lock, Delete) and one *Align* menu in plain language.
- The rail group *Document Studio* is now **Diagram Studio**.

## Known limits

- Generation covers Go and what Flow Intelligence reads (Java, XML, OSGi); other languages are not normalized yet.
- *Refresh from Code* updates the active page only. Callers and callees expand one hop per action.
- No filters by technology or confidence yet, and no breakpoint from a node.
- The desktop checks of the diagram + code split (resize, detached Code Studio) and of two open projects with same-named symbols are still manual.
