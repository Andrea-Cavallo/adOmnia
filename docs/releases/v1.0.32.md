# adOmnia v1.0.32

Control Code Studio through MCP, review individual AI changes, edit a React preview visually, and start architectural diagrams from four new examples.

## Agent IDE control and selective review

- MCP agents can open source files, start and inspect tests, control installed debuggers, read recent logs and query saved SQL connections. See [Agent IDE Control](../AGENT-IDE-CONTROL.md) for setup and tool contracts.
- The desktop bridge uses an authenticated loopback endpoint. Project tooling authorization and AI policy apply; execution, debugging, queries and review snapshots require MCP `--write`.
- Database queries run as bounded read-only transactions. Connection listings omit credentials.
- Review AI edits by line, range, function or file. Conflicting disk changes and unsaved editor buffers block selective actions; other pending edits remain available for review.
- External agents bracket edits with `ide_review_begin` and `ide_review_end`. Review snapshots remain in memory for the current application session.

## Live Preview Design Mode

- Edit supported React source through the preview: select elements, change text and styles, inspect layers, insert and reorder elements, undo, redo and save changes.
- The visual editor and its page bridge load on demand. See [Design Mode](../DESIGN-MODE.md) for supported projects and limitations.
- Includes the vendored Onlook sources and their Apache-2.0 license, with dependency license disclosures.

## Diagram Studio

- Change a legend row's color directly from its swatch on the canvas. Changes support undo, redo and autosave; locked legends stay locked.
- **Hexagonal checkout**: architectural and complex sequence presets showing ports and adapters, idempotency, an atomic order/outbox transaction, failures and asynchronous delivery.
- **Resilient catalog / cache-aside**: architectural and complex sequence presets showing concurrent readers, local singleflight, circuit breaking, stale responses and recovery.
- These four examples use colored native diagram shapes. Technology logos remain available in the icon library and the existing technology presets.

## Fixes and verification

- Resolved Go lint findings in the agent-control bridge: standard HTTP status constants and integer range loops.
- Automated frontend tests, production builds, startup checks and focused backend tests cover the integrated work. The Go lint run with `--build-tags gtk3 --timeout 8m` reports zero issues.
- Native desktop acceptance of the visual editing flow, live database-driver enforcement and macOS/Linux behavior remain manual checks. Browser fixtures and automated builds do not establish those results.
