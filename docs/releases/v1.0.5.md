# adOmnia 1.0.5 — revisione delle modifiche AI, aggiornamenti più sicuri, colori Go

16 ottobre 2026.

## Novità

- **Revisione delle modifiche degli agenti (Go Studio).** Dopo un turno di milk o Claude Code, i file creati, modificati o eliminati dall'agente compaiono sopra la chat e in *Tools → Review Agent Changes…*. Ogni blocco si accetta o si rifiuta da solo, oppure per file o tutto insieme. Un blocco rifiutato viene scritto solo se il file è ancora quello mostrato: una modifica successiva non viene mai sovrascritta.
- **Server MCP per Claude Code.** L'elenco *Context servers (MCP)* e il server integrato `adomnia mcp` (collection e mock server) arrivano davvero a Claude Code: prima `session/new` inviava sempre un elenco vuoto. milk usa un protocollo proprio e non li riceve ancora.
- **Regole del progetto nelle chat AI** (`.rules`, `AGENTS.md`, `CLAUDE.md`, `.cursorrules`), Query Console del Database Studio, pannelli Markdown e le altre novità dei tag 1.0.3 e 1.0.4: dettagli nel [CHANGELOG](https://github.com/Andrea-Cavallo/adOmnia/blob/v1.0.5/CHANGELOG.md).

## Correzioni

- **Aggiornamento in-app.** L'exe installato non viene più spostato né cancellato: il backup è una copia privata e la nuova versione entra con un rename atomico sopra la vecchia, con nuovi tentativi se un antivirus o OneDrive tengono il file. La nuova versione conferma l'avvio appena la finestra è pronta, senza attendere il caricamento del workspace; una versione che non corrisponde alla release fa ripristinare subito la precedente. `apply.log` registra ogni passo con l'orario.
- **Colori semantici nei file Go.** I file aperti mentre gopls caricava un progetto grande restavano con funzioni e tipi bianchi: le richieste fallite ora vengono ripetute con backoff e tutti i file aperti si aggiornano quando gopls finisce di caricare. Aprire un editor dell'API Studio non toglie più i colori al codice Go.

## Da sapere prima di aggiornare

L'aggiornamento in-app viene eseguito da un helper copiato dalla versione già installata. Il nuovo meccanismo di sostituzione vale quindi dagli aggiornamenti successivi alla 1.0.5: **installare questa versione a mano una volta** (scaricare l'exe e sostituire quello esistente).

## Verifica e attività ancora aperte

Test automatici eseguiti: `go test` di `internal/update` (compreso il test nativo di sostituzione e rollback e il nuovo caso di versione non corrispondente), `internal/ide/agentreview`, `internal/ide/fileio`, `internal/milk`, `internal/goide`; `npx tsc --noEmit`, test Vitest mirati, `npm run build` e `npm run check:startup`. La CI Windows esegue ora anche i test dell'updater.

Restano aperte le verifiche manuali nell'app elencate in [MANUAL-CHECK.md](https://github.com/Andrea-Cavallo/adOmnia/blob/v1.0.5/mds/MANUAL-CHECK.md), in particolare IDE-1 (aggiornamento e rollback firmati reali su Windows), GS-11 (revisione delle modifiche con un turno reale) e GS-12 (colori su un progetto grande).
