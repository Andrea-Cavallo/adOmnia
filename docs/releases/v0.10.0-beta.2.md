# adOmnia v0.10.0-beta.2

Second prerelease in the stabilization cycle toward v1.0.0. Not a declaration of desktop or multi-machine acceptance.

- Go Studio workspace intelligence: change impact (list, map, risk), architecture rules and drift, API and event contract drift, Runtime Snapshots, Startup and Shutdown analyzers, Binary Inspector, "why is this dependency here?", package heatmap.
- Go memory model helper: happens-before edges of channels, mutexes, WaitGroups, Once, atomics and go statements for the function under the cursor.
- Debugger: "Why is this running?" per goroutine (route or topic served, lifetime, context chain with deadlines, cancellation path); goroutines and variables load after a manual Pause.
- Status bar resource monitor (RAM/CPU), idle gopls lifecycle, taskbar icon following the palette, project PDF tools.
- V1 frontend scope tracked in [V1 release scope TODO](../../mds/V1-RELEASE-SCOPE-TODO.md).
