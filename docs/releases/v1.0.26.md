# adOmnia v1.0.26

A new look next to Dark and White, and two dead ends removed: installing several tools at once, and Database Studio crashing at startup.

## Anthracite

- **A complete theme in the Hub.** Choose *Anthracite* next to Dark, White and Custom. The editor is the darkest surface and the panels get lighter around it, in Code Studio and in the other modules.
- **Code colors too.** Keywords, types, functions, strings and comments have their own palette. Brackets are colored by depth. The terminal and JSON views use the same colors.

If you chose Anthracite in an earlier build, select it again: the old version was only a base color.

## Fixes

- **Installer: installing several tools no longer hangs.** With many tools selected, the confirmation grew taller than the window and opened behind the Installer, with no way to click it. Every confirmation in the app now stays on screen, on top of any window, and scrolls.
- **Installer: a progress bar.** *Install selected* shows the tool in progress and how many are done. Installs that end behind a closed dialog no longer look like they are still running.
- **Database Studio no longer crashes at startup.** Reopening the app on Database could end on "Something went wrong" (React error #301).
- **Settings > About lists the real licenses.** Every direct dependency, grouped by license, instead of an outdated list of eight.

## Also new

- **Large folders open progressively.** Code Studio streams long directory listings instead of waiting for all of them.
- **More languages in the Test tree.** Declared languages gain more test output parsers and coverage reports.
- **.NET SDK detection.** A missing SDK requested by `global.json` is explained.
- **Developer Context reads more project manifests.**
- **TOML in the editor.** Validation and completion through taplo, including its configuration file.
- **Find in Files in Settings.** See which ripgrep is in use and reinstall it.

## Known limits

- Installing all the language servers together has not been run end to end, and the progress bar says *Install finished* even when a tool failed: failures appear as a notice, in the tool's row and in the Run console.
- Verified by automated checks and in the Windows app. macOS and Linux builds pass CI; native visual acceptance on them is still manual.
