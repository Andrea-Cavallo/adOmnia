# adOmnia v1.0.31

Readable WebSocket messages and a Hub mini game you turn on yourself. The v1.0.30 tag never produced artifacts, so this is also the first published build with everything in [v1.0.30](v1.0.30.md).

## API workspace

- **Readable WebSocket messages.** Each message shows up to three lines of its payload in a larger font. The inspector gets more room and shows JSON as a tree three levels open (search, collapse, raw) and plain text at a readable size. *Expand*, or a double-click on a message, gives it the whole panel.
- **WebSocket connections follow the network settings** (from 1.0.30). The handshake goes through adOmnia's proxy (or the system's `HTTPS_PROXY`) and trusts the corporate CA, so `wss://` endpoints that worked in a browser or Postman no longer fail with `unexpected EOF` behind a corporate proxy.

## Hub

- **The mini game is off by default.** Turn it on in Settings → Feature Surface → *Hub mini game*.

## Also in this build (from 1.0.30)

- Java decompiler (Vineflower), JUnit Plug-in Tests for OSGi, saved changes that reach Tomcat for Eclipse WTP projects, and the Hub mini game with bosses. See [v1.0.30](v1.0.30.md).

## Known limits

Native acceptance in the desktop app remains manual. A proxy configured only through a PAC file or the Windows settings is not read: set it in Settings → Network.
