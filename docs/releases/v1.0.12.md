# v1.0.12 — v1.0.11 published

v1.0.11 was tagged but never published: the Linux job of its release build failed on a transient network error while verifying a Go module checksum (`sum.golang.org` closed the stream), so the GitHub Release step did not run. v1.0.12 contains the same code and publishes it.

- Python in Code Studio: interpreter per project unit, script/module Run, structured pytest tree with rerun failed, debugpy debugging and basedpyright editing (explicit install).
- Everything in [v1.0.11](v1.0.11.md): compact Code Studio header and tabs, safe document saves, Search Everywhere on Ctrl/Cmd+K, Chinese, Japanese and Russian UI catalogs.
- Everything in [v1.0.10](v1.0.10.md), which was prepared but never tagged: Installer, MCP server and client, Java studio improvements.

## Validation boundaries

The v1.0.11 code plus the Python adapter; the develop and main builds of this code passed in CI on every platform. Native visual and interactive acceptance remains explicit, as for v1.0.11.
