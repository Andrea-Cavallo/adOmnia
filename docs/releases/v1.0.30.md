# adOmnia v1.0.30

A Java decompiler, JUnit Plug-in Tests for OSGi, saved changes that reach Tomcat, WebSocket connections that work behind a corporate proxy, and a mini game in the Hub.

## Code Studio

- **Java decompiler.** Vineflower, installed once from the Java menu with a visible command, decompiles a `.jar`/`.war` of the project (*Decompile (Java)* in the tree) into a read-only cache. Libraries without a sources jar open decompiled in External Libraries. It runs on a JDK 11+ even when the project targets Java 6 or 8.
- **Saved changes reach Tomcat.** For Eclipse WTP projects the Java language server compiles into the output folder the `.classpath` declares (e.g. `build/classes`), which Tomcat publishes: no Ant build between an edit and a reload.
- **JUnit Plug-in Tests.** In a PDE workspace with a target, test files run inside Equinox like PDE's JUnit Plug-in Test; Eclipse's RemoteTestRunner reports fill the Test tree. Tycho `eclipse-test-plugin` modules run with `mvn verify`.

## API workspace

- **WebSocket connections follow the network settings.** The handshake goes through adOmnia's proxy (or the system's `HTTPS_PROXY`) and trusts the corporate CA, like HTTP requests. Behind a corporate proxy or firewall, `wss://` endpoints that worked in a browser or Postman used to fail with `unexpected EOF`. It also offers permessage-deflate like browsers do. A refused upgrade shows the server's status and answer; a dropped connection says where to look.

## Hub

- **Mini game.** A knight runs through an endless strip at the bottom of the Hub: arrows run, Space jumps, X slashes, C casts the lightning, Esc pauses. Every 20 seconds a boss (flying skull or ghost) warns before it dives and drops a chest when beaten: an extra heart, a wide golden slash or a shield. Each boss is tougher than the last. Keys are read only while the game has focus. Effects by pixelfx (MIT).

## Fixes

- The WebSocket round-trip tests no longer fail at random (they stopped the v1.0.29 tag build).
- The CI downloads of hadolint and actionlint survive GitHub's transient 504s; actionlint is built from the Go module proxy.

## Known limits

Native acceptance in the desktop app remains manual. A proxy configured only through a PAC file or the Windows settings is not read: set it in Settings → Network.
