# adOmnia v1.0.0

Local-first API workbench and Go Studio with connected database, broker, browser, logs and runtime tools. No cloud account required.

## Release scope

API Workspace, SOAP, gRPC, WebSocket/SSE, mock, proxy, Database and Broker Studio remain available. Go Studio supports multiple projects and native project windows within one application instance. AI and advanced analysis remain available. Imported PDFs, including project files, open the complete editor.

LAN collaboration remains beta and opt-in. Standalone PDF navigation, LaTeX, Kubernetes/OpenShift, plugin marketplace and Hub games are hidden; existing data and implementation are retained. See `mds/V1-RELEASE-SCOPE-TODO.md`.

## Delivery and known limits

Windows x86_64, Linux x86_64 portable and macOS universal packages are configured. Native acceptance remains open: native acceptance is not yet certified. Windows distribution currently uses an EXE and installation script, not a graphical MSI/Setup installer. Authenticode and Apple signing/notarization remain delivery gates. Linux package-manager repositories are outside this release scope.

Updater manifests are signed with the publisher Ed25519 key; downloads verify size and SHA256. This does not imply OS code signing. Real packaged update/rollback and workspace preservation must pass before publication.

Taskbar artwork uses the original skin-dependent monochrome logo. Palette recoloring is disabled pending native visual validation.

## Outstanding acceptance

Version 1.0.0 is set consistently in desktop and npm manifests. Published at the user’s explicit request with native acceptance still open in `docs/V1-CHECKLIST.md`; automated CI publication does not close those gates.
