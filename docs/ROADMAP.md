# Public Roadmap

This roadmap is intentionally product-focused. The detailed internal checklist lives in [docs/adomnia-roadmap-checkbox.md](adomnia-roadmap-checkbox.md).

## Current Focus

- Make the frontend feel like a coherent production desktop product.
- Connect existing backend capabilities to polished user workflows.
- Improve packaging and release confidence across Windows, Linux, and macOS.
- Keep local-first, privacy-first behavior visible and reliable.

## Near Term

- Finish request script runtime UX and result reporting.
- Strengthen workspace import/export flows.
- Improve API workspace polish: tabs, collections, environments, response history.
- Harden GitHub Actions release artifacts.
- Improve docs for install, build, release, privacy, and troubleshooting.

## Mid Term

- Improve Browser Debug integration as a first-class differentiator.
- Expand enterprise and legacy workflows: SOAP, WSDL, WS-Security, mTLS, JKS/eIDAS.
- Make proxy/interceptor workflows easier to inspect, replay, and export.
- Improve Docker Lab presets and local integration test stacks.
- Refine plugin and theme distribution.

## Later

- Code signing and macOS notarization.
- Linux package formats beyond portable tarballs.
- More workspace collaboration patterns while staying local-first.
- Deeper automation and runner reporting.

## Non-Goals

- Mandatory accounts.
- Cloud sync as a core dependency.
- Telemetry.
- Chasing test coverage numbers at the expense of product quality.
